# OMNIS Datasets & Provenance

This directory stores generated simulation artifacts, SQLite state databases, and world snapshots created by OMNIS 1.0.

## Provenance & Artifacts

- `omnis_state.db`: Primary SQLite persistence database storing `memories`, `organisms`, `experiments`, `audit_logs`, and `world_snapshots`.
- `omnis_demo.db`: SQLite database generated by `scripts/run_demo.py`.
- `demo_run_artifact.json`: End-to-end 10-step reproducible demonstration trace exported by `scripts/run_demo.py`.

All simulation artifacts include `schema_version`, `seed`, and ISO-8601 UTC timestamps for reproducibility.
